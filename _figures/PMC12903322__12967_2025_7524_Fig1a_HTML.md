caption: 'Markov clustering (inflation parameter = 3) of network propagation results
  shows functionally distinct gene modules. For each seed set (LBS6, IDH1, IDH2, and
  IDH1/IDH2), the top 100 propagated genes were grouped into three modules using Markov
  clustering based on STRING PPI connectivity and propagation score similarity. Each
  node represents a gene, color-coded according to cluster: red, green, or blue. (A)
  In the LBS6 network, clusters are enriched for platelet activation (red), fatty
  acid beta-oxidation (green), and sulfotransferase activity (blue). (B) In the IDH1
  network, clusters represent the citrate cycle (red), central carbon metabolism—including
  glycolysis and the pentose phosphate pathway (green)—and a nonspecific cluster (blue).
  (C) In the IDH2 network, clusters include the citrate cycle (red), carbon metabolism
  (green), and processes related to myelodysplastic syndrome and nuclear speck organization
  (blue). (D) The IDH1/IDH2 network recapitulates similar functional clusters observed
  in individual seeds, indicating overlapping but modular metabolic programs. Abbreviations:
  LBS6, literature-based six-gene signature; IDH1, isocitrate dehydrogenase 1; IDH2,
  isocitrate dehydrogenase 2; STRING, Search Tool for the Retrieval of Interacting
  Genes/Proteins; PPI, protein–protein interaction'
