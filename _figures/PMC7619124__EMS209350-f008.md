caption: The vitamin C transporter SVCT1 (SLC23A1) absorbs L-ascorbate (vitamin C)
  across the intestinal brush border membrane. How it leaves the epithelial cells
  is still unknown. There are two possible routes to the brain. 1) across the choroid
  plexus (blood-cerebrospinal fluid barrier) via the vitamin C transporter SVCT2 (SLC23A2)
  located in the basolateral membrane and GLUT12 (SLC2A12) located in the apical membrane
  of choroid plexus epithelial cells and then from the cerebrospinal fluid across
  the ependymal cell layer via unknown transporters; and 2) across the BBB as DHA
  via GLUT1/SLC2A1 (not shown; see Fig. 33). Since DHA is present in blood at relatively
  low concentrations compared to vitamin C, the SVCT2 route via the choroid plexus
  appears to be the predominant pathway. In neurons, vitamin C is oxidized to DHA,
  which is released by GLUT3 (SLC2A3). Astrocytes import DHA via GLUT1 and reduce
  it to vitamin C. The exit pathway of vitamin C from astrocytes is currently unknown.
  Neurons import vitamin C via SVCT2, closing the vitamin C recycling pathway. DHA
  is rapidly taken up by erythrocytes via the abundantly expressed glucose transporter
  GLUT1 (SLC2A1). Intracellularly, DHA is reduced to vitamin C by glutathione, glutaredoxin
  or thioredoxin reductase, with the end result of replenishing plasma vitamin C levels
