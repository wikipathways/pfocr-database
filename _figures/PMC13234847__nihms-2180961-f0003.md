caption: 'Recurrent allergen exposure can trigger IgE recall responses within peripheral
  tissues such as the lung, where resident memory B cells (BRMs) and local T helper
  cells operate within inducible tertiary lymphoid organs (TLOs), such as iBALT. Three
  non-mutually exclusive models may sustain local IgE immunity: (A) resident IgG1+
  memory reservoir model: IgG1+ BRMs receive IL-4/IL-13 from memory Th2/Tfh cells,
  undergo secondary class switching to IgE, and generate IgE+ antibody-secreting cells
  (ASCs). (B) Resident IgE+ memory reservoir model: tissue-resident IgE+ BRMs differentiate
  into IgE+ ASCs upon allergen rechallenge. (C) De novo IgE induction model: naive
  allergen-specific B cells recruited into iBALT undergo IgE class-switch recombination
  and differentiate into de novo IgE+ ASCs in response to local memory Th2/Tfh-derived
  cytokines'
